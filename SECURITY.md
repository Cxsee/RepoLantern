# Security

RepoLantern opens repositories you may not trust, so these count as vulnerabilities:

- code from an opened repository runs without you asking for it
- secret values are read, shown or sent anywhere
- a file outside the repository can be reached through RepoLantern
- an opened repository is modified without you asking for it

## Reporting

Please report privately, through [GitHub's private vulnerability reporting](../../security/advisories/new), not in a public issue. Include the steps to reproduce and the RepoLantern version.

This is a small project maintained in spare time, so there is no guaranteed response time.

## Supported versions

Only the latest release.
